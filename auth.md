# Google Sign-In Setup

This project uses Google Identity Services (GIS) to allow users to sign in with their Google accounts.

## Prerequisites

Before running the project, you must create a Google OAuth Client ID.

### Step 1: Create a Google Cloud Project

1. Visit the Google Cloud Console.
2. Sign in with your Google account.
3. Click **Select Project** → **New Project**.
4. Enter a project name.
5. Click **Create**.

---

### Step 2: Configure the OAuth Consent Screen

1. In the Google Cloud Console, navigate to:

   * APIs & Services → OAuth Consent Screen
2. Select **External** as the user type.
3. Click **Create**.
4. Fill in the required information:

   * App name
   * User support email
   * Developer contact email
5. Save and continue through the remaining steps.

---

### Step 3: Create OAuth Client Credentials

1. Navigate to:

   * APIs & Services → Credentials
2. Click **Create Credentials**.
3. Select **OAuth Client ID**.
4. Choose **Web Application**.
5. Enter a name for the credential.

---

### Step 4: Add Authorized JavaScript Origins

Add the URLs where the application will run.

#### Local Development

```text
http://localhost
http://127.0.0.1
http://localhost:5500
```

If you use VS Code Live Server, include:

```text
http://127.0.0.1:5500
http://localhost:5500
```

#### Production

Replace with your deployed website URL:

```text
https://your-domain.com
```

Example:

```text
https://furnix-home.netlify.app
```

---

### Step 5: Copy the Client ID

After creating the credential, Google will generate a Client ID similar to:

```text
248494341271-xxxxxxxxxxxxxxxxxxxxxxxx.apps.googleusercontent.com
```

Copy this value.

---

### Step 6: Add the Client ID to the Project

Locate the Google Sign-In initialization element:

```html
<div
    id="g_id_onload"
    data-client_id="YOUR_CLIENT_ID"
    data-callback="handleCredentialResponse"
    data-auto_prompt="false">
</div>
```

Replace:

```text
YOUR_CLIENT_ID
```

with your actual Google Client ID:

```html
<div
    id="g_id_onload"
    data-client_id="248494341271-xxxxxxxxxxxxxxxxxxxxxxxx.apps.googleusercontent.com"
    data-callback="handleCredentialResponse"
    data-auto_prompt="false">
</div>
```



## Testing Google Login

1. Open the application in your browser.
2. Click the Google Sign-In button.
3. Select a Google account.
4. After successful login:

   * The Google Sign-In button will be hidden.
   * User information will be stored in localStorage.
   * A Logout button will appear.

---

## Logout Behavior

When a user clicks Logout:

* User data is removed from localStorage.
* The Google Sign-In button becomes visible again.
* Google auto account selection is disabled.

---

## Common Errors

### Error: "The given origin is not allowed"

Cause:

The current website URL is not listed in Authorized JavaScript Origins.

Solution:

Add the exact URL in Google Cloud Console → Credentials → OAuth Client ID.

---

### Error: "Invalid Client ID"

Cause:

The Client ID was copied incorrectly.

Solution:

Verify that the Client ID exactly matches the value generated by Google Cloud Console.

---

### Error: Sign-In Button Does Not Appear

Check that the Google Identity Services script is loaded:

```html
<script src="https://accounts.google.com/gsi/client" async></script>
```

Also verify that:

* Internet connection is available.
* Browser extensions are not blocking Google scripts.
* The Client ID is valid.
