The Problem

The main navigation <ul class="navList" id="list"> originally contained a hardcoded aria-hidden="true" attribute. This permanently blocked screen readers from accessing the navigation links across all screen sizes, causing a major WCAG 2.1 compliance violation.

The Fix

  • Removed the hardcoded aria-hidden="true" from the navigation DOM.
  • Added dynamic state management based on viewport size.
  • Desktop (>= 992px): Navigation is always exposed (aria-hidden="false").
  • Mobile (< 992px): Navigation state dynamically mirrors the visual menu open/closed state.
  • Hamburger button correctly toggles aria-expanded.
  • Added semantic role="navigation" to parent <nav> element.

To test, resize your browser window below 992px to simulate mobile view and toggle the menu.
